# 금주노트 · NonAlcohol Note

술 없이 지낸 일수·아낀 돈을 보여주고, 술이 당기는 순간과 마신 술을 기록하도록 돕는 금주·절주 도우미 웹앱(PWA)입니다.
[금연노트](https://github.com/hyunjeongshin83/SmokeFreeNote) · [메디노트](https://github.com/hyunjeongshin83/MediNote) 와 같은 디자인·고령친화 원칙으로 만들었습니다.

## 화면
- **시작 설정** — 목표(술 끊기 · 줄이기), 시작일, 평소 마신 날 수·술값, 나의 이유. 오래 많이 마셨다면 갑자기 끊지 말고 의료진과 상의하라는 안내가 맨 위에 있습니다
- **오늘** — 술 없이 지낸 일수(초 단위), 술 없는 날, 아낀 돈(추정), 이번 주 마신 잔 수, 「지금 술이 당겨요」 5분 버티기
- **기록** — 넘겼어요 / 마셨어요(잔 수), 당긴 세기·기분·상황·넘긴 방법. 저장하면 그 자리에서 한 가지 제안
- **통계** — 지난 7일 마신 잔 수, 상황·기분 순위
- **도움** — 정신건강위기상담 1577-0199 · 자살예방 109 · 응급 119, 큰 글씨, 내보내기·가져오기

## 실행
`index.html` 을 브라우저로 열면 됩니다. GitHub Pages 에 올리면 휴대폰 홈 화면에 앱처럼 설치할 수 있습니다.
주소: https://hyunjeongshin83.github.io/NonAlcoholNote/

## 데이터
기록은 이 기기의 `localStorage` (`nonalcohol.v1`) 에 저장되며 앱이 서버로 보내지 않습니다.
다만 글꼴을 받으려고 앱을 열 때마다 fonts.googleapis.com · cdn.jsdelivr.net 에 접속하므로 IP·기기 정보는 그쪽에 남습니다.

> 금주노트는 음주 기록장이며 진단·치료를 대신하지 않습니다.
