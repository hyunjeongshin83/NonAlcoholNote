# 금주노트 — 설계 결정 (첫 버전 · 2026-10-15)

정한 것만 적습니다. 근거 조사(경쟁 앱 · 무작위 시험)는 아직 없습니다 — 다음 리서치 회차에서 `docs/COMPETITORS.md` 로 쌓습니다.

## 0. 시작 페이지 (대표님 요청 2026-10-15)
처음 열면 설정이 아니라 **시작 페이지**(맨 앞 탭 「시작」)가 먼저 나옵니다: 앱이 하는 일 · 3단계 · 시작하기 · 갑자기 끊지 말라는 안전 안내 · 약사·상담자와 함께 보기. 이후에는 오늘 화면으로 열리고 「시작」 탭에서 다시 볼 수 있습니다. 나중에 하위 메뉴로 옮길 수 있게 맨 앞 탭으로 둔 임시 배치입니다.

## 1. 틀
금연노트(SmokeFreeNote)의 틀을 그대로 옮겼습니다: 시작 설정 → 오늘 → 기록 → 통계 → 도움, 하단 탭, 5분 버티기, 내보내기·가져오기, 큰 글씨. 서버가 없고 알림도 아직 없습니다.

## 2. 기록 (`nonalcohol.v1` · `logs[]`)
| 칸 | 값 | 비고 |
|---|---|---|
| `kind` | `drink` 마셨어요 · `urge` 마시고 싶었는데 넘겼어요 | 필수 |
| `cups` | 마신 잔 수 (1~40) | `drink` 일 때만. 「표준잔」 환산은 하지 않음 — 잔 크기·도수를 확인하지 못했습니다 |
| `lv` | 약함 · 보통 · 강함 | 필수 |
| `mood` | 좋음 · 보통 · 나쁨 | 필수 |
| `trig[]` | 퇴근 후 · 식사 중 · 모임·회식 · 스트레스 · 외로움 · 지루함 · 주말 · 기쁜 일 | 여러 개 |
| `cope[]` | 물·차 · 심호흡 · 산책 · 연락하기 · 자리 피하기 · 간식 · 5분 버티기 | `urge` 일 때 |
| `t` | 저장 순간 | 자동 |

- 마신 날도 시도를 끝내지 않습니다. 「목표 다시 정하기」를 눌러야 `attempts[]` 에 `{start, end}` 로 남고 새 시작일을 받습니다.
- **아낀 돈(추정)** = 경과일 × (주당 마신 날 ÷ 7) × 한 번 술값 − (마신 날 수 × 한 번 술값). 음수면 0. 실제 지출이 아니라 설정값 기반 추정이며 화면에도 「추정」으로 적습니다.

## 3. 안전 안내
- 시작 화면 맨 위: 오래 많이 마셨다면 갑자기 끊기 전에 의료진과 상의, 떨림·식은땀·심한 불안·헛것이 보이면 진료·119. (알코올 금단은 위험할 수 있다는 일반 의학 안내)
- 도움 탭: 정신건강위기상담전화 1577-0199(24시간) · 자살예방상담전화 109 · 응급 119. 번호는 2026-10-15 에 검색 결과(서울시 · 쿠키뉴스)로 확인했고 배포 전 재확인이 필요합니다.

## 4. 아직 정하지 않은 것
- 선별 설문(AUDIT-C 등) 도입 여부 — 문구·점수 해석은 교수님 확인 필요
- 「표준잔」·저위험 음주 기준 — 기준 수치 확인 전에는 표시하지 않음
- 알림 기본값(금연노트 3절 참고) — 근거 조사 뒤
- 약사 상담 축 · 약물(날트렉손 등) 복약 칸 — 금연노트 1절 「앱 + 약사 상담」과 맞출지
- 안드로이드 셸 · Health Connect — 금연노트 `docs/NATIVE.md` 참고


## 시안 C·D 반영 (2026-10-15 · 대표님 선택)
- 색: 메디노트 틸로 통일 — `--g4/--g6 #0A7168` · `--g5/--g7 #06413E` (흰 바탕 5.87:1 · 흰 글자/#06413E 11.45:1, WCAG 상대휘도). `--g0`·`--g1` 은 `--d3` 글자 대비(#E1F1EE 에서 4.48:1)가 모자라 그대로 둠.
- 반응형: 폭 700px 이상에서 칸 최대 720px, 기록·통계·함께 보기는 두 칸.
- 「약사·상담자와 함께 보기」는 이제 앱 안 화면(`#v-pro`) — 내 기록에서 바로 요약(기간·당김 수·넘긴 비율·상황·기분) + 이름 없는 요약 CSV(수식 시작 글자 방지) + 전체 백업. 파일을 불러오지 않아 안드로이드 앱 셸에서도 열림.
- 이 화면은 진단·판정을 하지 않는다. 리서치 세션 내용은 아직 반영하지 않음(원문 확인 후).
